# Images

Screenshots and photos used in the guides go here. Link to them from a guide like this:

```markdown
![The Telia admin page](images/telia-admin-tiles.png)
```

## Before adding an image

Blur or crop out anything secret or personal:

- passwords, Wi-Fi keys and router stickers
- SSH keys, tokens and QR codes
- your home's public IP address
- MAC addresses and serial numbers
- names of other people's devices

Name files after the phase and what they show, for example `01-installer-storage.png` or `02-static-lease.png`.
